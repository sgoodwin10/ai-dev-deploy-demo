# The site's data layer

Everything the site shows about its own creation comes from JSON files in `site/data/`,
generated by `scripts/build-stats.mjs` on every CI run, agent run and production deploy.

**These files are generated — never edit or commit them** (`site/data/` and `site/evolution/`
are gitignored). To get fresh real data locally, run `npm run stats` (CI does this for you
before you start, so the files already exist in your workspace).

Design the page so it still looks intentional when numbers are small (day 1: one run, $0.40)
*and* when they are large (month 3: 400 runs). Handle empty arrays and `null` gracefully.
Fetch with relative URLs, e.g. `fetch('data/stats.json')`.

## Where the data comes from

| Source | Captured by | Lives in |
|--------|-------------|----------|
| Every Claude agent run (cost, tokens, turns, tool calls, excerpts, full step trace) | `scripts/telemetry/record.mjs` after each agent step | `telemetry` branch → `runs/`, `traces/` |
| Every production deploy (+ 4 screenshots of that version) | `deploy.yml` | `telemetry` branch → `deploys/`, `screenshots/` |
| Issues, PRs, review verdicts, lines changed | GitHub API at build time | — |

### `traces/<run id>.json` — replay of one run (load on demand, can be ~50 KB)
```jsonc
{ "id": "…", "steps": [ { "kind": "thought", "text": "…" }, { "kind": "tool", "tool": "Edit", "summary": "site/index.html (edit)" } ] }
```

### `daily.json` — for charts
```jsonc
[{ "date": "2026-11-05", "runs": 9, "costUsd": 4.1, "tokens": 0, "prsOpened": 3, "prsMerged": 2,
   "issuesOpened": 3, "deploys": 2, "failedDeploys": 0, "linesChanged": 540 }]
```

### `evolution.json` — the site at every deployed version (oldest first)
```jsonc
[{ "id": "20261105T093000-ab12cd3", "sha": "…", "title": "Add evolution scrubber", "pr": 13, "at": "…",
   "images": { "desktop": "evolution/…/desktop.jpg", "desktopDark": "…", "mobile": "…", "mobileDark": "…" } }]
```

### `deploys.json` and `prs.json`
Deploy records (`sha, title, pr, status, committedAt, finishedAt, url, runUrl`) and PR records
(`number, title, url, createdAt, mergedAt, state, additions, deletions, changedFiles, commits,
issues, reviews[{at, verdict, text}], labels`), newest first.
